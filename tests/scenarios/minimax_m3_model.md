# Сценарий: актуальный каталог MiniMax M3

Дата актуализации: 29.07.2026

## Предусловия

- Приложение запущено через `scripts/restart_app.ps1`.
- Для проверки реального ответа доступен MiniMax API key в тестовом профиле.

## Шаги

1. Открыть настройки LLM-профилей.
2. Создать новый профиль провайдера `MiniMax`.
3. Убедиться, что Base URL равен `https://api.minimax.io/v1`.
4. Убедиться, что по умолчанию выбрана модель `MiniMax-M3`.
5. Открыть список моделей.
6. Убедиться, что модели показаны в таком порядке:
   `MiniMax-M3`, `MiniMax-M2.7`, `MiniMax-M2.7-highspeed`,
   `MiniMax-M2.5`, `MiniMax-M2.5-highspeed`,
   `MiniMax-M2.1`, `MiniMax-M2.1-highspeed`, `MiniMax-M2`.
7. Убедиться, что `MiniMax-Text-01` и `abab7-preview` отсутствуют.
8. Сохранить профиль с API key, выбрать его активным и отправить в чат:
   `Ответь одним словом: готово`.
9. Дождаться завершения stream-ответа без ошибки API.

## Ожидаемый результат

- Новый MiniMax-профиль использует `MiniMax-M3`.
- Список соответствует официальному Chat Completions API.
- Запрос идет через OpenAI-compatible endpoint и возвращает ответ M3.

## Правило статуса

- `PASS` — UI и реальный облачный запрос проверены.
- `PARTIAL` — UI подтвержден, но облачный запрос не проверен из-за отсутствия API key.
- `FAIL` — список/модель неверны или доступный облачный запрос завершился ошибкой.
