# 1c-skills MCP Server

MCP-сервер для доступа к базе знаний агента: **скиллы**, **документация** и **правила кодирования 1С**.

Порт `mcp-skills.ts` (TypeScript/Node.js) на Rust. Standalone-бинарник — **не требует Node.js** и Tauri. Подключается к любому MCP-клиенту: opencode, Cursor, Claude Desktop.

## 📦 Сборка

```bash
cargo build --release
# → target/release/mcp-1c-skills (один исполняемый файл)
```

## 🛠 Инструменты

| Инструмент | Описание |
|---|---|
| `list_skills` | Список скиллов (опциональный фильтр по категории) |
| `get_skill` | Полное содержимое SKILL.md + список файлов скилла |
| `get_skill_file` | Чтение конкретного файла скилла (PS1-скрипт и т.д.) |
| `search_skills` | Поиск по названиям и описаниям скиллов |
| `list_docs` | Список документов (паттерны, соглашения) |
| `get_doc` | Полное содержимое документа по ID |
| `search_docs` | Поиск по документам |
| `list_rules` | Список правил кодирования 1С |
| `get_rule` | Полное содержимое правила по ID |

## 📁 Структура базы знаний

```
.agents/
├── skills/              # скиллы: <категория>/<скилл>/SKILL.md или плоские <скилл>/SKILL.md
├── docs/                # документация: **/*.md
└── rules/               # правила: **/*.md
```

## 🔍 Поиск каталога скиллов

Приоритет:

1. Переменная окружения `SKILLS_DIR`
2. `.agents/skills` рядом с бинарником, в `..` и `../..`
3. `~/.config/mini-ai-1c/.agents/skills`

## 🔌 Подключение (opencode)

```json
{
  "mcpServers": {
    "1c-skills": {
      "command": "/path/to/mcp-1c-skills",
      "env": { "SKILLS_DIR": "/path/to/.agents/skills" }
    }
  }
}
```

## ⚙️ Безопасность

- Защита от path traversal: ID скиллов и пути файлов валидируются (`..`, абсолютные пути запрещены).
- Только чтение: сервер не изменяет файлы.
