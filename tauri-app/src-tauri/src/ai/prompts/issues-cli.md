# Режим «Разработка» (Cli) — проблемы и план

> Режим: разработчик 1С, выполняет задачи разработки через файлы/песочницу,
> пишет код по стандартам 1С и БСП. Маркировка не требуется (экономия токенов).

## Зафиксированные проблемы (сессия 10:30–10:46, создание EPF)

Источники: `review.txt`, `reasoning.txt`, `mini-ai-1c-logs.txt` (2026-08-08).
Задача: создать внешнюю обработку «Получение компенсации по контрагенту» для ERP.

### P1. Поиск скиллов/документов не дал результатов
- `search_skills` по 1С-скиллам («внешняя обработка», «дополнительные отчеты») → пусто.
- `search_docs` по названию → пусто.
- **Причина**: в `mcp-1c-skills` были только dev-скиллы (Rust, TS, Tauri); 1С-скиллы
  появились позже в `config/skills/`. Агент остался без готовых скриптов
  (`epf-init`, `epf-build`, `epf-full-cycle`).
- **Решение**: см. общий план — подключить 1С-скиллы в `mcp-1c-skills`.

### P2. Спутан документ `epf-guide` со скиллом
- Агент вызвал `get_skill("epf-guide")` — но это документ (`list_docs`), не скилл.
- **Решение**: см. общий план — разметка ID (`[skill]`/`[doc]`) + проверка принадлежности.

### P3. Песочница (sandbox) пустая
- `list_directory` вернул пусто → агент создавал XML-структуру EPF с нуля вручную.
- **Решение**: инициализировать workspace (шаблон EPF / исходники) перед сессией.

### P4. Нашёл OneScript, хотя не требовался
- Агент потратил время на поиск OneScript-окружения; скрипты PowerShell уже были в скиллах.
- **Решение**: в промпт — «скрипты из скиллов приоритетны, если они есть».

### P5. Кодировка и кавычки в `run_command`
- Кириллица ломается в выводе PowerShell.
- Кавычки `"` превращаются в `\"` — агент придумал обход `~q~` → `[char]34`.
- **Решение**: см. общий план (P1 — встроить UTF8 + корректный экранинг).

### P6. Дрейф в рефакторинг вместо задачи
- Агент исправил чужую функцию `НаименованиеСкидокПоКлючуСвязи` (тире, пустой блок
  Иначе, `ИначеЕсли` без `Иначе`, неопределённая `КлючСтрокой`), прогнал
  `check_bsl_syntax` до чистоты — но **EPF так и не создал**.
- **Решение**: усилить приоритет выполнения задачи над «улучшениями» (см. P-план).

## План решения (для режима Cli)

| # | Проблема | Действие | Приоритет |
|---|----------|----------|-----------|
| 1 | Нет 1С-скиллов в mcp-1c-skills | Подключить `config/skills/` (или worktree) к серверу скиллов | P0 |
| 2 | Дрейф в рефакторинг | В `CLI_IDENTITY`: «Сначала заверши запрошенное. Улучшения — только по явной просьбе или списком после выполнения» | P1 |
| 3 | OneScript вместо скриптов | В промпт: «Если в скиллах есть скрипты (.ps1/.py) для задачи — используй их в первую очередь» | P1 |
| 4 | Пустой sandbox | Предзаполнять workspace шаблоном/исходниками перед стартом | P2 |
| 5 | Кодировка | Общий фикс `run_command` (UTF8) | P1 |
| 6 | Спутанные ID скиллов/доков | Общая разметка ID | P2 |
